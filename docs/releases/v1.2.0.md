AirPods Mic Bridge 1.2.0 adds light/dark appearance and six interface languages.

- Automatic Windows app theme or manual Light/Dark selection.
- Tray contrast follows the actual taskbar theme, including mixed light/dark settings.
- Automatic Windows UI language or Русский, English, Español, Português (Brasil), Português and Bahasa Indonesia.
- Language/theme choices apply immediately and are saved alongside the notification-card preference.
- Portable per-user settings and local diagnostics; no fixed drive is required.

The red 48×48 corner indicator stays visible while muted. Microphone signal level fills only the tray icon's capsule. The optional notification card remains disabled by default. Microphone control behaviour is preserved.

Download the ZIP and run `AirPodsMicBridge.exe`. EXE, English/Russian documentation and SHA-256 checksums are also attached separately. Requirements and Bluetooth/MagicAAP limitations are described in the README.

Checked: C# 5 x64 build; 447 localization assertions; 60 presentation/settings checks without audio recording or mute changes.
