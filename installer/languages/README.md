# Installer translation source

`Indonesian.isl` is adapted from the official Inno Setup repository,
tag `is-6_7_3`, commit `4adf37ed7f3fd2bd11c6836ba056e3de170fbabf`:

https://github.com/jrsoftware/issrc/blob/4adf37ed7f3fd2bd11c6836ba056e3de170fbabf/Files/Languages/Unofficial/Indonesian.isl

Upstream SHA-256: `EDA27CA7D4B0BD666D7ED0CC91A856842A0101D7CFF12417998CFD1E12C92FBA`.

The translator's original attribution comments are preserved. Inno Setup lists
this contributed translation as unofficial; it is not included in its standard
compiler distribution. The other five installer languages come from Inno Setup.

The upstream file still targets Inno Setup 6.4. Obsolete messages are removed
or renamed, and the new download, archive and verification messages are translated
for 6.7.3, so the wizard does not fall back to English for missing messages.
