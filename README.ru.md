# AirPods Mic Bridge

Утилита Windows превращает одиночное нажатие на AirPods в переключение системного микрофона, пока приложение активно использует микрофон AirPods. Для голосовых приложений и сайтов в браузере действует одно правило.

[English](README.md) · [Скачать релизы](https://github.com/goodserg/AirPodsMicBridge/releases) · [История изменений](CHANGELOG.md)

## Запуск

1. На Windows 11 x64 скачайте и запустите `AirPodsMicBridge-1.3.0-Setup.exe` из релиза. Сначала выберите **Для текущего пользователя** (по умолчанию, без прав администратора) или **Для всех пользователей** (нужны права администратора), затем папку установки. На последнем шаге флажки **Запустить AirPods Mic Bridge** и **Запускать вместе с Windows** включены по умолчанию. Нужен .NET Framework 4.x.
2. Подключите AirPods, выберите их микрофон в голосовом приложении или на сайте в браузере и начните использование микрофона.
3. Нажмите на ножку один раз для выключения микрофона, ещё раз для включения. Нажатие должно поступать в Windows как команда «Воспроизвести/пауза».

Установщик поддерживает те же шесть языков, что и приложение, и создаёт ярлык в меню «Пуск». Для переносного запуска скачайте ZIP релиза, распакуйте и откройте `AirPodsMicBridge.exe`. ZIP не создаёт автозапуск автоматически; ранее созданный автозапуск может оставаться включённым. Пункт **Запускать вместе с Windows** в меню трея меняет автозапуск для вашей учётной записи.

Значок микрофона в трее имеет прозрачный фон. Заливка внутри капсулы показывает текущий уровень сигнала; запись звука не производится. Красный с X означает выключенный микрофон, контур — включённый, серый — ожидание подключения или приостановленное управление.

Красный индикатор **48×48 физических пикселей** остаётся точно в верхнем левом углу основного экрана, пока наблюдаемый микрофон AirPods выключен. После включения зелёный появляется на 2,2 секунды. Индикаторы пропускают клики и не забирают фокус.

Правый щелчок по значку в трее открывает меню:

- Включение и приостановка управления микрофоном.
- Включение и выключение запуска вместе с Windows.
- Всплывающая карточка, **выключенная по умолчанию**.
- Тема: **Автоматически (Windows)**, светлая, тёмная.
- Язык: **Автоматически (Windows)**, Русский, English, Español, Português (Brasil), Português, Bahasa Indonesia.
- Диагностика гарнитуры.
- Выход.

Автовыбор учитывает язык интерфейса Windows. Для неподдерживаемого языка используется английский; бразильский вариант португальского определяется отдельно. Изменения применяются сразу и сохраняются. Автотема меню и карточки соответствует теме приложений Windows, а контраст значка — теме панели задач, даже если они различаются. Изменения темы Windows проверяются раз в секунду. Красный и зелёный цвета углового индикатора сохраняются во всех темах.

Примеры оформления; необязательная карточка включена для этого превью.

## Поведение и совместимость

- Переключается системный mute устройства записи; это влияет на все приложения, использующие тот же микрофон. Кнопка mute самого приложения может показывать другое состояние. Системное переключение не включает отключённую дорожку микрофона в браузере и не меняет кнопку mute сайта.
- Управление работает, когда у одного однозначно выбранного устройства AirPods есть активный сеанс записи Windows. Учитываются браузерные и системные сеансы; списка разрешённых приложений, окон или сайтов нет. Проверка микрофона тоже может активировать управление, поэтому активный сеанс не доказывает, что идёт звонок. Другой микрофон вместо AirPods не выбирается.
- В этом состоянии любая команда Windows «Воспроизвести/пауза», в том числе с другой клавиатуры, гарнитуры или приложения, может переключить mute. Вне этого состояния команда выполняет обычное действие. Сразу после окончания использования микрофона устаревший результат опроса может подавить одну команду; рабочий поток повторно проверит состояние и отменит переключение.
- Если активное устройство AirPods нельзя выбрать однозначно, состояние сеанса неизвестно или обнаружена ошибка чтения AirPods, управление приостанавливается.
- Кнопка mute приложения может оставить сеанс записи открытым или освободить его. Если активных сеансов больше нет, нажатие не переключает микрофон. Сначала возобновите использование микрофона в приложении, затем используйте AirPods для системного mute.
- Красный индикатор отслеживает внешнее изменение mute и вне активного использования микрофона, когда подключённый микрофон AirPods определяется однозначно.
- Выход и обновление сохраняют текущее состояние mute. Автозапуск можно изменить в меню трея.

Проверенная аппаратная конфигурация — AirPods 4 с **включённым драйвером MagicAAP**. Утилита использует обычные Windows API и не обращается к драйверу напрямую. Работа без него зависит от того, передаёт ли Bluetooth наблюдаемую команду нажатия во время использования микрофона; этот вариант **пока не проверен**. Определение активного микрофона без привязки к приложению не означает, что все приложения и Bluetooth-драйверы проверены физически. Утилита не изменяет приложения и Bluetooth-драйверы.

Определение активности использует стандартные аудиосеансы Windows. Монопольный режим и пути захвата ASIO не проверены и могут требовать аппаратного mute устройства; программное переключение mute не гарантирует управление такими путями.

## Настройки и диагностика

Настройки: `%LOCALAPPDATA%\AirPodsMicBridge\settings.json`.

Папка установки по умолчанию — `%LOCALAPPDATA%\Programs\AirPodsMicBridge` для текущего пользователя или `%ProgramFiles%\AirPodsMicBridge` для всех пользователей. На странице выбора папки её можно изменить. Настройки и диагностика остаются в личной папке данных каждого пользователя. При удалении программы файлы и ярлык автозапуска этой установки удаляются, а пользовательские данные сохраняются.

**Запускать вместе с Windows** использует принадлежащий приложению ярлык с аргументом `--autostart`. Установка для текущего пользователя использует `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`, для всех — общую папку `%PROGRAMDATA%\Microsoft\Windows\Start Menu\Programs\Startup`. Пункт меню трея управляет автозапуском для текущей учётной записи. Если есть общий ярлык, выключение сохраняет личный маркер отказа без прав администратора; общий ярлык остаётся для остальных пользователей. Повторное включение удаляет этот маркер.

Локальные журналы: `%LOCALAPPDATA%\AirPodsMicBridge\logs`. В них есть названия, идентификаторы и изменения состояния аудиоустройств, но нет записи звука, истории уровня сигнала и произвольного ввода с клавиатуры. Данные никуда не отправляются. Для разработки и тестирования переменная `AIRPODS_MIC_BRIDGE_DATA` переопределяет всю папку данных.

Завершение из командной строки:

```powershell
.\AirPodsMicBridge.exe --stop
```

## Диагностика гарнитуры

Откройте **Диагностика гарнитуры** в меню трея или запустите `AirPodsMicBridge.exe --diagnostics`. Выберите исследуемый микрофон; можно проверять и гарнитуры других производителей.

Мастер использует выбранные тему и язык. Тема применяется к заголовку, списку микрофонов, полосе прогресса и кнопкам, включая отключённые.

1. Начните звонок или проверку микрофона в другом приложении, затем нажмите **Начать**.
2. Нажимайте кнопку гарнитуры один раз по каждой из шести подсказок с интервалом пять секунд. Проверка остановится через 30 секунд; кнопка **Остановить** завершает её раньше.
3. Нажмите **Сохранить отчёт…** и выберите, куда записать файл JSONL.

На время проверки утилита приостанавливает управление микрофоном. Гарнитура и другие приложения могут выполнять собственные действия по нажатию. Отчёт содержит время событий, медиакоманды Windows, например «Воспроизвести/пауза», «Стоп» и громкость, доступные HID-отчёты управления мультимедиа и телефонией, изменения mute и активности микрофонов, а также названия, версии и INF-идентификаторы установленных звуковых, Bluetooth и HID драйверов. MagicAAP включается в список и при регистрации в другом классе устройств. Звук, история уровня сигнала и обычный ввод с клавиатуры не записываются.

Исходные отчёты остаются в `%LOCALAPPDATA%\AirPodsMicBridge\diagnostics`; сохранение создаёт копию в выбранном месте. Названия и идентификаторы устройств могут содержать заданное вами имя гарнитуры или Bluetooth-адрес. Автоматической отправки нет; личные отчёты не входят в файлы релиза.

Проверка видит события, которые Windows предоставляет приложениям. Она не перехватывает пакеты Bluetooth и не раскрывает команды, которые закрытый драйвер обрабатывает внутри себя. Наличие драйвера в списке не доказывает, что он создал записанное событие. Диагностика помогает исследовать поддержку другой гарнитуры; управление микрофоном пока предназначено для AirPods.

## Сборка

```powershell
.\build.ps1
.\test.ps1
.\build-installer.ps1 -CompilerPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
.\package.ps1
```

Для приложения используется штатный компилятор C# из .NET Framework, C# 5, x64. Внешние библиотеки и сетевые загрузки не нужны. Для сборки установщика дополнительно нужен Inno Setup 6.7.3; индонезийский перевод включён в исходники с указанием источника. Программа собирается в `dist\AirPodsMicBridge`. Временные файлы находятся в системной временной папке; параметр `-BuildRoot` задаёт другую. Проверки не переключают микрофон и не записывают звук, а личные и общие ярлыки автозапуска создают в изолированных папках. Сначала соберите установщик, затем запускайте упаковку: ZIP и SHA-256 создаются в `dist`, установочный EXE тоже включается в контрольные суммы релиза.

`test-installer.ps1 -CompilerPath <ISCC.exe>` проверяет установку, обновление и удаление на шести языках. Создаёт временные папки программы, ярлыков и данных и отдельную запись удаления текущего пользователя; затем удаляет тестовую установку. Для проверки общей автозагрузки используется отдельная тестовая папка. Эти проверки не устанавливают рабочую программу для всех пользователей и не меняют настоящее приложение или папки автозапуска.

Для установки без мастера используйте `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` и `/CURRENTUSER` или `/ALLUSERS` для выбора области установки. Установка для всех пользователей требует повышения прав. Автозапуск включён по умолчанию; `/STARTUP=no` отключает его, в том числе при обновлении. Язык установщика задаётся через `/LANG=en|ru|es|ptBR|pt|id`, где `ptBR` — бразильский португальский. Язык приложения по-прежнему определяется по Windows, пока вы не выберете его вручную в меню. Для управления общим ярлыком автозапуска из командной строки запустите `AirPodsMicBridge.exe --startup-enable-all-users` или `--startup-disable-all-users` с правами администратора.

System DPI-aware manifest сохраняет физический размер индикатора 48×48 на основном экране. Правила выбора устройства и потоков описаны в [архитектуре](docs/architecture.md).

Публичный репозиторий доступен для просмотра и скачивания. Прямой доступ на запись есть только у владельца и явно назначенных сопровождающих; при публикации дополнительные участники не добавляются. Рисунок углового индикатора воспроизведён по предоставленному образцу интерфейса. Проект независим от Apple и производителей Bluetooth-драйверов.
